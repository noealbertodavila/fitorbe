PROBLEMA 1 — DASHBOARD DEL CLIENTE QUEDA EN BLANCO
═══════════════════════════════════════

Cuando el cliente inicia sesión y hace clic en cualquier opción del menú, la página queda sin datos.

SOLUCIÓN:
1. Al cargar el dashboard del cliente, hacer fetch de TODOS los datos de una vez:

async function cargarDashboardCliente() {
  const clienteId = usuarioLogueado.id;
  const token = localStorage.getItem('token');
  const headers = { Authorization: `Bearer ${token}` };
  const hoy = new Date().toISOString().split('T')[0];
  const semanaActual = obtenerLunesActual();

  const [perfil, rutina, nutricion, progreso, mensajes, emocional, pagos] = await Promise.all([
    fetch(`/api/clientes/${clienteId}`, {headers}).then(r => r.json()).catch(() => null),
    fetch(`/api/rutina/${clienteId}/${semanaActual}`, {headers}).then(r => r.json()).catch(() => null),
    fetch(`/api/plan-comida/${clienteId}/${semanaActual}`, {headers}).then(r => r.json()).catch(() => null),
    fetch(`/api/progreso/${clienteId}`, {headers}).then(r => r.json()).catch(() => []),
    fetch(`/api/mensajes/${clienteId}`, {headers}).then(r => r.json()).catch(() => []),
    fetch(`/api/emocional/${clienteId}`, {headers}).then(r => r.json()).catch(() => []),
    fetch(`/api/pagos/${clienteId}`, {headers}).then(r => r.json()).catch(() => [])
  ]);

  renderizarTodo(perfil, rutina, nutricion, progreso, mensajes, emocional, pagos);
}

2. Las secciones del cliente (Inicio, Mi Rutina, Mi Nutrición, Mi Progreso, Bienestar, Mensajes, Mi Plan, Mis Pagos) deben ser tabs que muestran/ocultan contenido YA CARGADO — nunca navegar a otra URL

3. Si alguna sección no tiene datos mostrar mensaje amigable:
- Mi Rutina: "Tu coach aún no ha asignado una rutina esta semana 💪"
- Mi Nutrición: "Tu coach aún no ha asignado un plan de comidas esta semana 🥗"
- Mi Progreso: "Aún no hay registros — ¡agrega tu primer registro hoy! 📸"
- Mensajes: "No tienes mensajes aún — escríbele a tu coach"
- Mi Plan: mostrar el plan contratado con todas sus características

PROBLEMA 2 — MÓDULO DE PROGRESO FOTOGRÁFICO MENSUAL

- Botón verde grande: "+ Agregar registro del mes"
- Solo habilitado si no hay registro del mes actual
- Si ya hay registro del mes, mostrar: "Ya registraste este mes — próximo registro disponible el [fecha]"

B) FORMULARIO DE REGISTRO MENSUAL (modal o página completa):

PASO 1 — FOTOS (6 posiciones):

- Al seleccionar foto: mostrar preview de la imagen
- Formatos: JPG, PNG — máximo 5MB
- Las fotos son opcionales — no todas son obligatorias

PASO 2 — MEDIDAS CORPORALES:
Dividido en 3 grupos:

- Edad metabólica (años)
