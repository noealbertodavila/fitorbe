Corrige el sistema de mensajes leídos en el dashboard del cliente:

PROBLEMA:
El badge de mensajes no leídos sigue mostrando "2" aunque el cliente ya leyó los mensajes. Debe desaparecer al abrir la conversación.

1. Al abrir la sección Mensajes, marcar TODOS como leídos automáticamente:
async function marcarMensajesLeidos() {
  const token = localStorage.getItem('nahofitToken');
  const usuario = JSON.parse(localStorage.getItem('nahofitUsuario'));
  
  try {
    await fetch(`/api/mensajes/marcar-leidos`, {
      method: 'PUT',
      headers: {
        'Content-Type': 'application/json',
        Authorization: `Bearer ${token}`
      },
      body: JSON.stringify({ receptor_id: usuario.id })
    });
    
    // Actualizar badge inmediatamente
    const badge = document.getElementById('badge-mensajes');
    if (badge) badge.style.display = 'none';
    
    // Actualizar título pestaña
    document.title = 'NAHOFIT.LIFE';
    
    // Ocultar banner si existe
    const banner = document.getElementById('banner-mensaje');
    if (banner) banner.style.display = 'none';
    
  } catch(e) {
    console.log('Error marcando leídos:', e);
  }
}

2. Llamar marcarMensajesLeidos() en estos momentos:

PUT /api/mensajes/marcar-leidos
